# Phase 3 On-Demand ETA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add explicit, mode-selected route calculation from บ้านสุภา to the active place with zero automatic route requests.

**Architecture:** Put all route calls behind one runtime service with an in-memory session cache keyed by place + mode. UI selection is inert; only the calculate action invokes the service. Google usage is logged through the existing budget/request tracking layer.

**Tech Stack:** Google Routes API, TypeScript, React, Vitest, existing Google API budget logging.

**Spec:** `docs/superpowers/specs/2026-09-17-phase-3-decision-intelligence-design.md`

## Global Constraints

- Open app/list/detail = 0 route requests.
- Selecting travel mode = 0 requests.
- Calculate = exactly 1 request for selected mode.
- Modes: walking, motorcycle/two-wheeler, driving.
- Never infer route duration from Haversine distance.
- Fresh provider results remain runtime/transient; do not overwrite canonical route fields.
- Recalculate is the only intentional bypass of the session cache.
